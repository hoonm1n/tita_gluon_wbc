## 회전 오차가 형성된 시간과 해석

| 평가 환경 | E 10–20초 → 50–60초 | H 10–20초 → 50–60초 |
| --- | ---: | ---: |
| sim2sim `impratio=100` | 0.1401 → 0.1463 | 0.0464 → 0.0464 |
| sim2sim `impratio=1` | 0.1256 → 0.1257 | 0.0635 → 0.0635 |
| native mjlab | 0.1252 → 0.1254 | 0.0586 → 0.0586 |

각 셀은 좌우 0.5·1.0·1.5 rad/s 회전에서 seed별 최악 잔류 `vx` MAE의 군별 중앙값(m/s)이다. H의 군 중앙값은 세 환경 모두 10–20초에 이미 E보다 낮았고 50–60초에도 비슷했다. 이 조건에서 긴 회전 경험은 회전 중 지속되는 전진 속도를 줄일 수 있었지만, 세 seed에서의 일관성과 고속·자세 성능 보존이 부족했다. H는 총 회전 스텝을 맞추는 대신 재추출 횟수를 줄였으므로, 결과는 더 긴 명령과 더 적은 명령 전환을 묶은 학습 조건의 효과로 해석한다. [평가 환경별 회전 vx·vy·yaw rate 및 피치·높이](turn_windows.csv)

`gamma`와 `n_step`은 이번 비교의 고정 변수였다. 이번에는 오차가 10–20초에 이미 형성됐고 고속 전진과 자세 추종의 회귀가 더 큰 제약이었다. 이 데이터는 Gamma와 n-step을 곧바로 넓게 탐색하기보다, 동일 정책이 회전 오차 개선과 기존 주행·자세 성능을 함께 달성하는 조건을 우선 찾는 쪽을 지지한다. [기존 속도 편향과 접촉 조건 분석](../../2026-11-20/speed_tracking_cause_summary.md)
